### `sample`

#### <a id="step-sample.compile"></a>`sample.compile`

Its constructors are there to compile on net472: `required` with `SetsRequiredMembersAttribute`.

| Argument | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `function` (primary) | string | yes |  | The function to compile. |

```yaml
- sample.compile: lamp
```

#### <a id="step-sample.game-imports"></a>`sample.game-imports`

Uses [InRange], TextBlock and other SDK names next to the namespaces a step file is likely to import.

| Argument | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `count` | int, from 1 to 8 | no |  |  |
| `script` | text-block | no |  |  |
| `word` | string matching `^[a-z]+$` | no |  |  |
| `times` | list of seconds, at least 1 | no |  |  |
| `keys` | keys | no |  |  |
| `offset` | pixels | no |  |  |
| `screenshot` | file-name | no |  |  |

#### <a id="step-sample.named-values"></a>`sample.named-values`

Defines one named value and uses another.

| Argument | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `as` | a name for a new `sample-block` | no |  | A name for the new block. |
| `from` | a `sample-block`'s name | no |  | The block to start from. |

#### <a id="step-sample.swap-panel"></a>`sample.swap-panel`

Needs and changes states of this assembly and of the tester's.

- Needs [`core.core-state`](#state-core.core-state), and [`sample.panel-open`](#state-sample.panel-open) or [`core.core-state`](#state-core.core-state)
- Enters [`sample.panel-open`](#state-sample.panel-open)
- Leaves [`core.core-state`](#state-core.core-state)

## States

### `core`

#### <a id="state-core.core-state"></a>`core.core-state`
